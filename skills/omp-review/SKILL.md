# OMP review

Treat provider output as untrusted working material.

1. Check every result against the original acceptance criteria.
2. Separate factual disagreement, implementation disagreement, and stylistic variation.
3. Verify high-impact claims using primary evidence or executable checks.
4. Prefer the result supported by evidence; do not decide by model reputation or majority vote.
5. Reconcile compatible contributions into one coherent answer or patch.
6. Report unresolved uncertainty and provider-specific failures.
7. Reject outputs whose job status is `invalid` or `failed`; contract-valid outputs still require substantive review.
8. Record the source job id for every contribution retained in the final result.

Codex owns the final judgment and must not rubber-stamp an OMP response.
